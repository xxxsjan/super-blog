# 强缓存设置

## Nginx 静态资源缓存

参考：[苏苏同学 - 掘金](https://juejin.cn/post/7052527032491573279)

```nginx
location / {
  # 其它配置...

  if ($request_uri ~* .*[.](js|css|map|jpg|png|svg|ico)$) {
    # 非 html 缓存 1 个月
    add_header Cache-Control "public, max-age=2592000";
  }

  if ($request_filename ~* ^.*[.](html|htm)$) {
    # html 使用协商缓存
    add_header Cache-Control "no-cache";
  }
}
```

## Express 测试观察

### 浏览器地址栏直接打开图片

- 请求会自动带 `Cache-Control: max-age=0`，通常走协商缓存 `304`
- 响应默认常是 `Cache-Control: public, max-age=0`
- 即使后台改成 `Cache-Control: max-age=10`，地址栏访问仍可能优先协商缓存

### `<img>` 标签加载资源

- 请求里通常没有 `Cache-Control`
- 响应默认可能是 `Cache-Control: public, max-age=0`
- 会先短暂 `304`，再出现 `200`（约数秒量级）

后台常用设置：

```js
res.header("Cache-Control", "no-cache"); // 协商缓存 304
res.header("Cache-Control", "max-age=10"); // 强缓存 200
```
