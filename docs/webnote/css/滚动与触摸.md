# 滚动与触摸

## touchmove 触发滚动

### 解决 1：监听 touchmove 并按需 preventDefault

```js
const vm = this;
document.addEventListener(
  "touchmove",
  function (event) {
    if (vm.isMove) {
      event.preventDefault();
    }
  },
  {
    passive: false,
  }
);
```

### 解决 2：使用 `touch-action`

应用 CSS 属性 `touch-action: none;`，触摸不会产生默认行为，但 `touch` 事件仍会触发。

更多选项见 [MDN: touch-action](https://developer.mozilla.org/zh-CN/docs/Web/CSS/touch-action)

```css
/* 全局只允许纵向滚动 */
* {
  touch-action: pan-y;
}

/* 或禁用某容器的默认触摸行为 */
.container {
  touch-action: none;
}
```

## 一行 CSS 提升页面滚动性能

参考：[掘金文章](https://juejin.cn/post/7134648288925450248)

```css
body {
  pointer-events: none;
}
```
